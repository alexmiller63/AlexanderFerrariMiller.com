# Nativitas aspect interpretation library

Modern Western tropical astrology, informed by classical tradition.

## Editorial policy
- Exactly one entry per unordered planetary pair and major aspect.
- Ten planets yield 45 pairs and 225 entries.
- Write specific, readable interpretations; avoid repeated prefatory caveats.
- A single disclaimer belongs in the UI: astrology is not scientifically validated.
- Distinguish traditional seven-planet material from later modern interpretations.
- Record verifiable bibliographic references per entry before publication. Do not imply a source supports exact wording unless checked.
- Status `draft-awaiting-source-verification` means **not approved for publication**.
- This catalog is currently **not wired into the natal chart generator**.

## Schema
`pair`: two lowercase planet IDs in `planet_order`; `aspect`: one of five major aspects; `text`: original editorial summary; `tradition`: interpretive school; `status`: review gate; `sources`: checked citations (empty until verified).

## Reference candidates to check
C. E. O. Carter, *The Astrological Aspects* (1930); Robert Hand, *Horoscope Symbols* (1981); contemporary natal-aspect references for outer planets. These are **research candidates**, not verified citations for the draft entries.
