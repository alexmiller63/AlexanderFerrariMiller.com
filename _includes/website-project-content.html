AlexanderFerrariMiller.com

A working professional website and reusable publishing architecture built to present a many-sided career without sacrificing clarity, maintainability, or mobile usability.

The project

AlexanderFerrariMiller.com brings professional work, performance, teaching, projects, social media, history, and multiple targeted resumes into one coherent site. The site is also an engineering project: its structure is designed to be understandable, testable, reusable, and easy to extend.

Architecture

Content and wrappers

Substantial page content is separated from thin Jekyll wrappers, keeping each layer focused and independently inspectable.

Reusable includes

Shared headers, navigation, footers, cards, and styles provide consistency while avoiding duplicated page structure.

Mobile-first presentation

Responsive grids, flexible type, compact navigation, and carefully sized media keep the site useful on phones and larger screens.

Progressive expansion

New professional roles, project pages, resume cards, formats, and mini-sites can be added without rebuilding the whole site.

Resume publishing

A custom generator turns structured resume source material into synchronized HTML, PDF, DOCX, and ODT editions. The resume page presents each professional emphasis as its own card, with clear viewing, downloading, and source options.

C-3PO document viewer

The site includes a browser-based document-viewing system designed to make resume PDFs readable without forcing an immediate download. It supports direct viewing while preserving access to downloadable office-document formats.

A site within a site

The Kilroy mini-site demonstrates that the architecture can support a distinct visual identity and subject while remaining connected to the main website. It uses period styling, historical material, original imagery, and its own navigation hierarchy.

Kilroy Project

Result

The project is both a live professional home and a reusable model for personal websites that need to organize varied identities, projects, documents, and media without becoming overwhelming.
