Ephemera

Positions and rise/set times at a date, time and observing location.

Ephemeris generator

Enter a UTC date/time and observing coordinates. The calculation engine uses local JPL/NAIF source kernels to determine the apparent positions of the Solar System and numerically solve each body's horizon crossings.

Example: 2026-10-22T21:00:00Z. The rise/set events are for the UTC calendar date containing this instant. Current kernel coverage: 1900–2100.

This website is static. For now, calculations run in GitHub Actions; no sign-in is required to prepare the inputs here, but triggering a run requires access to GitHub.

What the report contains

      
Sun, Moon, Mercury, Venus, Mars, Ceres, Jupiter, Saturn, Uranus, Neptune and Pluto. Earth is the observer's origin, not an output row. The HTML and JSON reports include right ascension, declination, ecliptic coordinates, altitude, azimuth, and rise/set events.

      
Method and limitations

      
Positions are recalculated as time advances; rise/set times are not estimated from the weekly 9 PM snapshot. Values are provisional pending validation. The model uses approximate horizon thresholds without local terrain or weather corrections, and the time scan may miss grazing events.
