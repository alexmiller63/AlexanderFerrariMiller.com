# Constellation stories

Authoritative story drafts for the 88 canonical IAU constellations. Serpens has one article shared by its two portraits. Mensa and Microscopium have histories even though their stick figures are permanently absent from this atlas.

Each lower-case constellation-name Markdown file contains an IAU abbreviation, name, pending status, author credit, Hed, Dek, body, and a compact Sources section with clickable references. Cards and articles should draw their Hed and Dek from this source.

Write in alphabetical order, save each completed draft individually, then update `progress.json`. Resume at the first unsaved constellation, reconciling files against the index if interrupted between writes. Do not wait for batch approvals.

`status: pending` means the draft still requires its accuracy and plagiarism audits. Saving a draft does not attest that a source-overlap review, finder check, publication check, or audit has passed. Do not publish these drafts until the agreed prepublication audit is complete.

Mensa and Microscopium articles must eventually link to the existing explanatory article about their missing stick figures; resolve that article's actual URL before adding the link.

`progress.json` records saved drafts, audit state, and the next constellation. This collection uses constellation identities, not fabricated fixed-object IDs.
