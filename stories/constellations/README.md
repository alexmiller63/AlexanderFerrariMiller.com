# Constellation stories

All **88 canonical constellation story drafts** are saved, from [Andromeda](andromeda.md) through [Vulpecula](vulpecula.md). The full file list and audit states are recorded in [progress.json](progress.json).

Serpens has [one article](serpens.md) shared by its two portraits. [Mensa](mensa.md) and [Microscopium](microscopium.md) have histories and link to the existing [explanation of the figure convention](../../front-matter.md#whats-up-with-mensa-microscopium-and-serpens).

Each lower-case constellation-name Markdown file contains an IAU abbreviation, name, pending status, author credit, Hed, Dek, body, and a Sources section with clickable references. Cards and articles should draw their Hed and Dek from this source.

The alphabetical drafting pass is complete. Each article was saved individually and the progress index updated after each save. A subsequent read of all 88 articles verified unique canonical identities, alphabetical ordering, required metadata, substantive bodies, and source sections.

`status: pending` means the draft still requires its accuracy and plagiarism audits. The completeness check does not attest that a source-overlap review, finder check, publication check, or accuracy audit has passed. Do not publish these drafts until the agreed prepublication audit is complete.

This collection uses constellation identities, not fabricated fixed-object IDs.
