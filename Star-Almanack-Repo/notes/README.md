# Star Almanack Notes Index

The original `../notes.md` is preserved as the historical append-only project log. New durable design rules should be recorded in the topic files below so notes remain small, retrievable, and maintainable as the Almanack expands across many years.

- `calendar.md` — calendar inclusion, visibility-day, and deduplication rules.
- `constellations-asterisms.md` — constellation boundaries, geometric centers, and asterism definitions.
- `stars.md` — star-note editorial policy and star-specific inclusion relationships.
- `ephemeris.md` — ephemeris and notation conventions.
- `eclipses-meteors.md` — eclipse and meteor calendar policy.
- `finders.md` — finder and sky-orientation conventions.
- `pipeline.md` — generalized multi-year generation architecture.
- `history.md` — pointer to the preserved legacy chronological log.

Do not delete or silently rewrite historical decisions. When a rule changes, append a dated replacement rule and identify what it supersedes.
