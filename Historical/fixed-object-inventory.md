# Star Almanack Master Fixed-Object Inventory

## Mandatory objects

1. All 110 Messier objects, M1 through M110.

2. Every Bayer α star that exists in the 88 modern constellations.

3. Every Bayer β star that exists in the 88 modern constellations.

## Bayer systems

A Bayer designation represents one Almanack object.

Multiple catalog components such as:

- α¹ / α² Centauri

- α¹ / α² Librae

- β¹ / β² Scorpii

- β¹ / β² Sagittarii

remain associated with the same Bayer-system entry unless Star Almanack

explicitly promotes a component to its own object entry.

## Additional objects

Scientifically, historically, culturally, or observationally important stars

may be added outside the α/β rule.

Example:

- Proxima Centauri

## Preserved source data

For each fixed object preserve, where applicable:

- Almanack name

- catalog designation

- Bayer designation

- constellation

- component information

- right ascension

- declination

- precise visual magnitude

- object type

- source

## Reader-facing magnitude

Preserve the precise magnitude in the source data.

In dated Almanack best-visibility entries, present stellar magnitude as the

whole-number magnitude class:

mag 1

mag 2

mag 3

mag 4

mag 5

mag 6

Constellation charts retain magnitude to one decimal place.

## Best-visibility calculation

For a fixed object with right ascension α_object:

α_Sun = α_object - 9h

Find the annual instant when the apparent Sun reaches that right ascension.

Round the resulting instant to the nearest calendar date.

That date is the Star Almanack best-visibility date.

Also record the corresponding ISO week-date.
